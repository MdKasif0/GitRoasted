# **App Name**: GitRoast

## Core Features:

- GitHub Profile Search: Allow users to search for GitHub profiles using a username.
- GitHub API Proxy: Proxy requests to the GitHub API to fetch user data.
- Roast Generation: Use AI to generate a roast based on the user's GitHub commit history; incorporate humor by finding questionable coding habits in the data as a tool.
- Scoring Algorithm: Calculate a roast score based on the user's commit history.
- Profile Card Display: Display user profile information, including roast score and AI-generated roast.
- Leaderboard: Store user data and roast scores using Netlify KV to create a leaderboard of roasted users.
- Shareable Card: Allow users to share their roast and score as a shareable card.

## Style Guidelines:

- Primary color: Vibrant orange (#FF8C00) to reflect the fiery roast theme, taken from the logo.
- Background color: Dark, desaturated indigo (#1A237E) to provide a contrasting backdrop.
- Accent color: Purple (#7B1FA2) to complement the orange and add visual interest.
- Body and headline font: 'Inter' for a clean, modern look. It will be suitable for both headlines and body text.
- Use fire-related icons to represent the roast theme. (e.g. flames, chili peppers).
- Use glassmorphism style card layouts for the profile card and roast display. Employ a modern and intuitive design.
- Add subtle animations for a smooth user experience, such as score changes and generating roasts.
